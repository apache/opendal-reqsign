# Community

Reqsign is an independent library developed in the open as a subproject of
[Apache OpenDAL™](https://opendal.apache.org/). It is governed by the Apache
OpenDAL PMC and shares the OpenDAL community's infrastructure — one community,
two products.

## Reqsign-specific entry points

- **[GitHub issues](https://github.com/apache/opendal-reqsign/issues)** — bug
  reports and feature requests.
- **[GitHub discussions](https://github.com/apache/opendal-reqsign/discussions)**
  — questions and design conversations.
- **[Contributing guide](https://github.com/apache/opendal-reqsign/blob/main/CONTRIBUTING.md)**
  — how to build, test, and land a change.

## Shared OpenDAL community channels

- **Mailing list** — [dev@opendal.apache.org](mailto:dev@opendal.apache.org)
  ([subscribe](mailto:dev-subscribe@opendal.apache.org),
  [archives](https://lists.apache.org/list.html?dev@opendal.apache.org)).
  Project decisions happen here, Reqsign's included.
- **[Discord](https://discord.gg/XQy8yGR2dg)** — chat with the OpenDAL and
  Reqsign community.
- **[OpenDAL community handbook](https://opendal.apache.org/community/)** —
  governance, roles, and processes that apply to both products.

## Security

Report security issues privately following the
[ASF vulnerability handling process](https://www.apache.org/security/) —
never through public issues.

## The Apache Way

Reqsign follows the [Apache Way](https://www.apache.org/theapacheway/):
community over code, open decisions on the mailing list, and releases voted
by the PMC. Everyone is welcome — using, reporting, documenting, and
reviewing are all contributions.
