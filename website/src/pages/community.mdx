# Community

Apache Reqsign™ is a top-level project of the Apache Software Foundation,
governed by its own Project Management Committee. It started inside
[Apache OpenDAL™](https://opendal.apache.org/) and graduated to a standalone
project in 2026; OpenDAL remains one of its largest users.

## Where things happen

- **Mailing list** — [dev@reqsign.apache.org](mailto:dev@reqsign.apache.org)
  ([subscribe](mailto:dev-subscribe@reqsign.apache.org),
  [archives](https://lists.apache.org/list.html?dev@reqsign.apache.org)).
  Project decisions, release votes, and design discussions happen here.
- **[GitHub issues](https://github.com/apache/reqsign/issues)** — bug
  reports and feature requests.
- **[GitHub discussions](https://github.com/apache/reqsign/discussions)**
  — questions and longer design conversations.
- **[Discord](https://discord.gg/XQy8yGR2dg)** — real-time chat, shared with
  the OpenDAL community.
- **[Contributing guide](https://github.com/apache/reqsign/blob/main/CONTRIBUTING.md)**
  — how to build, test, and land a change.

## Security

Report security issues privately following the
[ASF vulnerability handling process](https://www.apache.org/security/) —
never through public issues.

## The Apache Way

Reqsign follows the [Apache Way](https://www.apache.org/theapacheway/):
community over code, open decisions on the mailing list, and releases voted
by the PMC. Everyone is welcome — using, reporting, documenting, and
reviewing are all contributions.
